# Tugas 04 GitHub Actions

Project Maven ini memuat implementasi dan unit test untuk:

- validasi pendaftaran;
- perhitungan nilai mahasiswa;
- rekening bank sederhana sebagai studi kasus bonus.

Jalankan pengujian dan laporan coverage dengan:

```bash
mvn test
mvn jacoco:report
```

Laporan JaCoCo dihasilkan pada `target/site/jacoco/index.html`.
